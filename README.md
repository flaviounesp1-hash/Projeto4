# Projeto4
Trabalho acadêmico com site da ONG fictícia Quatro Patas
Em fase de pré-lançamento.
Há problemas já identificados  de visualização incorreta e de padronização de estilos nas páginas de visualização da galeria de fotos dos animais abrigados e também  na página de cadastro de interessados em adoção, doação, apadrinhamento ou trabalho voluntário na ONG.
A página de doação precisa ser completada com as informações da conta para transferência e cards com valores pré-definidos para estimular a doação.
