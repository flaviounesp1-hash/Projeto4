# Projeto4
Trabalho acadêmico com site da ONG fictícia Quatro Patas
Em fase de pré-lançamento (v.0.0.1).
Descrição: apresenta o site da ONG Quatro Patas
Utilização: 
1. faça o download do repositório Projeto4 para sua máquina
2. abra o arquivo index.html na raiz do diretório para iniciar a navegação
3. a navegação é comandada principalmente pelo barra de menu fixa no topo de cada página acessada

Problemas da versão de pré-lançamento
1. Visualização incorreta na galeria de fotos dos animais abrigados
2. Padronização de estilos nas páginas da galeria de fotos dos animais abrigados
3. Padronização de estilos  na página de cadastro de interessados em adoção, doação, apadrinhamento ou trabalho voluntário na ONG.

Objetivos do novo release (v.0.0.2)
1. A página de doação precisa ser completada com as informações da conta para transferência e cards com valores pré-definidos para estimular a doação.
2. Implementar a funcionalidade "enviar cadastro" na página de cadastro.
